# Micro SaaS Team — WDLON

A reusable skills-only Codex plugin for researching, validating, specifying, building and improving micro-SaaS products for wdlon.com.

Example requests:

- “Use Micro SaaS Team to research three recurring problems WDLON could solve for London service businesses.”
- “Use Micro SaaS Team to validate this idea and write its MVP PRD.”
- “Use Micro SaaS Team to build the approved MVP in this repository.”
- “Use Micro SaaS Team to review this SaaS for launch readiness.”

The package includes one coordinating skill with focused validation, delivery and source references. It adds no MCP servers, hooks, external credentials or scheduled jobs. Research and development use tools already available to the host.
