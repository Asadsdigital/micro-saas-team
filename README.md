# Micro SaaS Team for WDLON

A reusable Codex plugin for finding paid problems, validating demand, writing product requirements, building focused MVPs and checking launch readiness.

## Install

Add this repository as a plugin marketplace, then install the plugin:

```sh
codex plugin marketplace add Asadsdigital/micro-saas-team
codex plugin add micro-saas-team@wdlon-local
```

Restart Codex if the newly installed plugin does not appear in the current session.

## Use

“Use Micro SaaS Team to research three recurring problems WDLON could solve for London service businesses.”

“Use Micro SaaS Team to validate this idea and write its MVP PRD.”

“Use Micro SaaS Team to build the approved MVP in this repository.”

“Use Micro SaaS Team to review my SaaS for launch readiness.”

## Included

- One coordinating skill with research, validation, product, engineering, QA and growth perspectives.
- Demand validation and unit economics guidance.
- PRD, implementation and launch checklists.
- Source provenance for the two referenced Instagram reels and user-supplied transcript.
